# Roadmap Standard

## Purpose

The roadmap standard keeps institutional public status precise and evidence-backed.

## Required Fields

| Field | Requirement |
| --- | --- |
| Item | Public-safe name. |
| Status | One approved status label. |
| Owner | Foundation authority or boundary owner. |
| Evidence | Public URL if `published` or `released`; blank or planned note otherwise. |
| Boundary | What the item does not claim. |
| Review gate | Required review before stronger status. |

## Rule

Roadmap items may describe planned work, but planned work is not a public commitment, live program, deployment, released artifact, or public report.
