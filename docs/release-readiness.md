# Release Readiness

## Purpose

This file defines what must happen before any roadmap item can move to `released`.

## Required Evidence For `released`

| Artifact Type | Required Evidence |
| --- | --- |
| Public report | Reviewed report, publication date, authority note, correction path, and boundary note. |
| Model | Public Hugging Face repo, model card, safety notes, limitations, release notes, and review record. |
| Dataset | Public dataset repo, dataset card, provenance/license posture, sanitation review, and review record. |
| Space | Public Space, README, dependency review, safety boundary, and review record. |
| Program update | Reviewed public evidence, privacy review, location/safety review, and status owner. |
| School or NEURONA update | Student/privacy/security review and public evidence. |

## Current Position

All non-repository artifacts listed by this roadmap remain `planned` unless separately reviewed and linked.
