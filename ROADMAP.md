# Public Roadmap

## Purpose

This roadmap records institutional public repository work for the 218-network GitHub organization. It is a status ledger, not a promise of live programs, deployments, reports, models, datasets, Spaces, services, schools, NEURONAs, outcomes, or timelines.

## Current Public Repo Stack

| Item | Status | Evidence | Boundary |
| --- | --- | --- | --- |

| `foundation-governance` | `published` / `scaffolded` | https://github.com/218-network/foundation-governance | Templates and synthetic examples; real governance docs require review. |

| `foundation-public-reports` | `published` / `scaffolded` | https://github.com/218-network/foundation-public-reports | Templates and synthetic examples only. |
